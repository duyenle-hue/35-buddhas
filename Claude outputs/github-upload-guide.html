Step-by-step guide

Upload "35 Budhas" to GitHub

Your folder has a ready-to-publish website inside it. This guide takes you from zero to GitHub in 10 minutes.

🌐 website/ — the website (index.html + images)
🖼️ Photos/ — 35 high-res source photos
📄 Research Notes.txt
Part 1 — Create the repository on GitHub.com
1

Go to GitHub and sign in (or create an account)

Open your browser and go to github.com. If you don't have an account yet, click Sign up and create a free one. It only takes a few minutes.

💡 A free GitHub account is all you need. No credit card required.
2

Create a new repository

Once signed in, click the + button in the top-right corner → New repository. Then fill in:

• Repository name: 35-buddhas
• Description: optional — e.g. "Website about the 35 Buddhas"
• Visibility: Public (so the website can be seen by others) or Private (just for you)
• ❌ Do NOT check "Add a README file" — leave all checkboxes empty

Click Create repository.

⚠️ Leave "Add a README", "Add .gitignore", and "Choose a license" all unchecked. If you add them, the push will fail.
3

Copy your repository URL

After creating the repo, GitHub shows a page with setup instructions. Look for the URL in the "…or push an existing repository" section. It looks like:

Your URL will look like this
https://github.com/YOUR-USERNAME/35-buddhas.git
💡 Copy this URL — you'll need it in Step 6.
Part 2 — Open Command Prompt and run git commands
4

Open Command Prompt in your folder

Open File Explorer and navigate to your 35 Budhas folder. Then click the address bar at the top, type cmd, and press Enter. A black Command Prompt window will open already inside that folder.

💡 Alternatively: press Windows key + R, type cmd, press Enter, then paste the command below to navigate there.
Alternative — navigate manually
C:\> cd "C:\35 Budhas"
5

Initialize git and add your files

Run these commands one by one. After each one, press Enter and wait for it to finish before typing the next.

Command 1 of 3 — Initialize git
> git init
Command 2 of 3 — Add all files
> git add .
Command 3 of 3 — Save a snapshot (commit)
> git commit -m "Initial commit: 35 Buddhas project"
💡 git add . means "add ALL files in this folder." The dot (.) means "everything here."
6

Connect your folder to GitHub

Replace YOUR-USERNAME in the command below with your actual GitHub username, then run it.

Connect to GitHub — replace YOUR-USERNAME
> git remote add origin https://github.com/YOUR-USERNAME/35-buddhas.git
7

Push (upload) everything to GitHub

This is the final command. It uploads all your files to GitHub. It may take a minute because of the photos.

Upload to GitHub
> git push -u origin main
⚠️ GitHub may ask for your username and password. For the password, use a Personal Access Token (not your account password). Generate one at: github.com → Settings → Developer Settings → Personal Access Tokens → Tokens (classic) → Generate new token. Give it "repo" permission.
✅
Done! Your files are on GitHub.
Go to github.com/YOUR-USERNAME/35-buddhas to see everything uploaded. You should see all three folders and files there.
Optional — Publish the website for free
★

Turn on GitHub Pages (free website hosting)

GitHub can host your website/ folder as a live website anyone can visit — for free.

1. On your repo page, click Settings
2. In the left sidebar, click Pages
3. Under "Source," select Deploy from a branch
4. Choose branch: main, folder: /website
5. Click Save

After a minute, your site will be live at:
https://YOUR-USERNAME.github.io/35-buddhas/

💡 It may take 1–2 minutes for the site to go live after saving.
